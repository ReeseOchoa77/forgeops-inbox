# `@forgeops/web`

ForgeOps React + Vite UI (`apps/web`). Production host: Vercel (`forgeops-inbox.com`).

Local: `npm run dev:web` from the repo root (http://localhost:5173, proxies `/api` to the API).

Onboarding and architecture: [`../../README.md`](../../README.md) and [`../../docs/README.md`](../../docs/README.md).

This package is not a generic Vite template. Do not follow the default plugin-react README as product documentation.
